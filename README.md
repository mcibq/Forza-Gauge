# Forza Gauge
Simple telemetry app for Forza Horizon 6 based on existing project by austinbaccus:

https://github.com/austinbaccus/forza-telemetry

## Compiling the app

Requirements:
* NET.Framework 4.8
* Visual Studio 2022 or higher

## Running the app
Download ForzaGauge.exe from Releases or compile code and run ForzaGauge.exe  
Best resolution: 1920x1080 or more.

## Configuration
Forza Horizon 4, 5, 6

1. Launch the game and proceed through the menus until you can drive your car
2. Pause the game and navigate to the Settings menu
3. Navigate to HUD and Gameplay
4. Set Data Out to ON
5. Set Data Out IP Address to 127.0.0.1
6. Set Data Out IP Port to 5300
7. Click Connect on Forza Gauge app
8. Text "Game paused" should appear at the bottom left in Forza Gauge app when in a menu of Forza

## Features
* Average speed and Distance for races
* Top speed (session)
* Tire temperature
* Reset button for Top & Avg speed & Distance
* G-Force diagram
* RPM bar
* RPM+/RPM- for adjusting RPM bar
